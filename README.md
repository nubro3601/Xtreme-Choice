# Xtreme Choice

Premium electronics ecommerce front end with an admin dashboard.
Brand theme: blue, black and white.

## Colors

| Name | Hex |
|---|---|
| Deep Black | `#080D18` |
| Royal Blue | `#2563EB` |
| Pure White | `#FFFFFF` |
| Navy Blue | `#0F172A` |
| Light Blue | `#60A5FA` |
| Light Grey | `#F1F5F9` |

All colors are CSS variables at the top of `css/style.css`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Pages

- Storefront: `index.html`
- Admin dashboard: `index.html#admin`

## Structure

```
index.html
css/style.css
js/app.js
```

## Deploy on GitHub Pages

Push to GitHub, then go to Settings > Pages and select the `main` branch, root folder.
